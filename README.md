# Noise Point｜要嘛安靜，要嘛算數學

教室音量偵測網頁：放在投影機上，全班太吵就跳出一題數學，題目會累積在畫面上，學生在數學作業簿寫題號和計算過程。倒數結束後，統整頁列出這節課出過的題目和答案，給老師檢查有沒有漏寫、對答案。

## 怎麼開啟

麥克風在瀏覽器裡有安全限制，**需要用 https 網址或本機伺服器開啟**，直接雙擊 `index.html` 有些瀏覽器會擋。

- 本機測試：在這個資料夾執行 `python -m http.server 5173`，再用 Chrome 或 Edge 打開 `http://localhost:5173`。
- 正式使用：放到 GitHub Pages，用固定網址打開。

## 上課流程

1. **上課時間**：選 10、20、40 分鐘，或自己輸入。
2. **音量門檻**：按「啟用麥克風」，拖曳黑色直線或選「安靜／小聲討論／分組討論」。第一次在新教室使用，建議按「校正這間教室」（5 秒安靜＋5 秒說話）。
3. **出題範圍**：先選年級，再選上學期或下學期，勾選已經教過的單元（上、下學期可以分開勾，也可以兩邊都勾）。
4. 按「開始上課」。上課中：
   - 稍微超過門檻持續約 3 秒、或大幅超過約 1 秒，就出一題；掉書、關門這種短暫聲響不會出題。
   - 新題目先放大顯示 10 秒，之後縮進題目區，一直留在畫面上。
   - 出題後冷卻 20 秒，冷卻完還是吵才出下一題；預設最多 6 題。
   - 老師講課時按**空白鍵**暫停偵測，倒數照走；再按一次繼續。
   - 「結束」可以提早進入統整頁。
5. 統整頁的答案預設隱藏，按「顯示答案」才出現；可以列印或存成 PDF。最近 10 次紀錄可在「歷史紀錄」查看。

冷卻秒數、題數上限、放大顯示秒數可以在「進階設定」調整，設定會自動記住。

## 隱私

- 麥克風只用來計算音量大小，**不錄音、不儲存、不上傳**。
- 不需要登入，不收集學生資料。設定和紀錄只存在這台電腦的瀏覽器（localStorage），清除瀏覽器資料就會刪除。
- 本專案沒有任何金鑰或後端。

## 題庫

| 冊別 | 狀態 |
|---|---|
| 3 上 | 9 個單元可出題 |
| 3 下 | 8 個單元可出題（第 9 單元「統計表」需要看表，不出題） |
| 4 上 | 9 個單元可出題（第 10 單元「統計圖」需要看圖，不出題） |
| 4 下 | 10 個單元可出題 |
| 5 上 | 10 個單元可出題（第 7 單元「線對稱圖形」只出對稱軸條數，題型較少） |
| 5 下 | 10 個單元可出題（第 5 單元只出大數，不出折線圖） |
| 6 上 | 9 個單元可出題 |
| 6 下 | 6 個單元可出題（第 6 單元只出圓形圖的計算題，不出畫圖與可能性） |

3～6 年級下學期的最後一個單元是「**學習扶助**」（3 下第 10、4 下第 11、5 下第 11、6 下第 7 單元），全部是四選一選擇題：

- 一半機率抽**原題**：每個年級 150 題（111～115 年考古題＋模擬卷 A），題目附原圖。統整頁的答案後面會註明出處，例如「③ 9/8 盒　［113 年第 8 題］」。
- 一半機率由**電腦出題**：依 [docs/學習扶助命題原則.md](docs/學習扶助命題原則.md) 寫成的出題規則，數字隨機產生，錯的選項來自學生常見錯誤。
- 原題來源：[學扶數學](https://teacher-liujikan.github.io/xuefu/)。考古題著作權屬教育部國民及學前教育署；模擬卷 A 為原網站作者原創，僅供教學使用，請勿商用。
- 原題資料 `js/questions/xuefu-data.js` 與圖片 `assets/xuefu/` 由 `tools/xuefu_build.py` 產生。

一般單元：

- 題型參考該冊的月考卷與課本，數字由程式隨機產生，不收錄原題。
- 3、4 年級尚未學約分，分數答案不約分（與考卷一致）。
- 5、6 年級分數答案寫成最簡分數（5 年級考卷也接受未約分的寫法）；6 年級圓周率用 3.14。

### 新增冊別

1. 在 `js/questions/` 新增一個檔案（例如 `g2a.js`），照 `g4a.js` 的格式註冊冊別與單元。
2. 在 `index.html` 依年級順序加上 `<script defer src="js/questions/g2a.js"></script>`，並在 `js/app.js` 的 `GRADES` 加上年級。
3. 在 `tests/check.js` 的 `BOOK_FILES` 加上冊別代號，執行 `node tests/check.js`，確認每個出題規則跑 3,000 次都沒有錯誤。

## 檔案結構

```
index.html             畫面結構
css/style.css          樣式（淺色高對比，適合投影）
js/app.js              主程式：設定、上課、統整頁、歷史紀錄
js/audio.js            麥克風音量計算（Web Audio API）
js/detector.js         「太吵判定」規則
js/render.js           題目顯示（直式分數）
js/storage.js          本機儲存
js/questions/core.js   題庫核心（隨機出題、避免重複）
js/questions/g3a.js    3 上出題規則（g3b 為 3 下，以此類推到 g6b）
js/questions/xuefu.js  學習扶助單元：電腦出題規則與註冊
js/questions/xuefu-data.js  學習扶助原題（由 tools/xuefu_build.py 產生）
assets/xuefu/          學習扶助原題的圖片
docs/學習扶助命題原則.md   學習扶助的命題原則（電腦出題依據）
tools/xuefu_build.py   把學扶數學網站的題目轉成 Noise-Point 格式
js/watermark.js        著作權浮水印
tests/check.js         題庫與判定規則自我檢查（node tests/check.js）
textbooks/             課本與考卷（有版權，已排除於 Git 之外）
```

## 開發用：測試模式

網址加上 `?test`（例如 `http://localhost:5173/?test`）會改用假麥克風，可在瀏覽器主控台輸入 `NP.testLevel = 80` 模擬吵鬧、`NP.testLevel = 10` 模擬安靜。上課時不要使用這個網址。
