# Noise Point｜要嘛安靜，要嘛算數學

教室音量偵測網頁：放在投影機上，全班太吵就跳出一題數學，題目會累積在畫面上，學生在數學作業簿寫題號和計算過程。倒數結束後，統整頁列出這節課出過的題目和答案，給老師檢查有沒有漏寫、對答案。

## 怎麼開啟

麥克風在瀏覽器裡有安全限制，**需要用 https 網址或本機伺服器開啟**，直接雙擊 `index.html` 有些瀏覽器會擋。

- 本機測試：在這個資料夾執行 `python -m http.server 5173`，再用 Chrome 或 Edge 打開 `http://localhost:5173`。
- 正式使用：放到 GitHub Pages，用固定網址打開。

## 上課流程

1. **上課時間**：選 10、20、40 分鐘，或自己輸入。
2. **音量門檻**：按「啟用麥克風」，拖曳黑色直線或選「安靜／小聲討論／分組討論」。第一次在新教室使用，建議按「校正這間教室」（5 秒安靜＋5 秒說話）。
3. **出題範圍**：先選年級，再選上學期或下學期，勾選已經教過的單元（上、下學期可以分開勾，也可以兩邊都勾）。
4. 按「開始上課」。上課中：
   - 稍微超過門檻持續約 3 秒、或大幅超過約 1 秒，就出一題；掉書、關門這種短暫聲響不會出題。
   - 新題目先放大顯示 10 秒，之後縮進題目區，一直留在畫面上。
   - 出題後冷卻 20 秒，冷卻完還是吵才出下一題；預設最多 6 題。
   - 老師講課時按**空白鍵**暫停偵測，倒數照走；再按一次繼續。
   - 「結束」可以提早進入統整頁。
5. 統整頁的答案預設隱藏，按「顯示答案」才出現；可以列印或存成 PDF。最近 10 次紀錄可在「歷史紀錄」查看。

冷卻秒數、題數上限、放大顯示秒數可以在「進階設定」調整，設定會自動記住。

## 隱私

- 麥克風只用來計算音量大小，**不錄音、不儲存、不上傳**。
- 不需要登入，不收集學生資料。設定和紀錄只存在這台電腦的瀏覽器（localStorage），清除瀏覽器資料就會刪除。
- 本專案沒有任何金鑰或後端。

## 題庫

| 冊別 | 狀態 |
|---|---|
| 4 上 | 9 個單元可出題（第 10 單元「統計圖」需要看圖，不出題） |
| 4 下 | 10 個單元可出題 |
| 5 上、5 下、6 上、6 下 | 尚未建立 |

- 題型參考該冊的月考卷與課本，數字由程式隨機產生，不收錄原題。
- 4 年級尚未學約分，分數答案不約分（與考卷一致）。

### 新增年級

1. 在 `js/questions/` 新增一個檔案（例如 `g5a.js`），照 `g4a.js` 的格式註冊冊別與單元。
2. 在 `index.html` 的 `g4b.js` 後面加上 `<script defer src="js/questions/g5a.js"></script>`。
3. 執行 `node tests/check.js`，確認每個出題規則跑 3,000 次都沒有錯誤。

## 檔案結構

```
index.html             畫面結構
css/style.css          樣式（淺色高對比，適合投影）
js/app.js              主程式：設定、上課、統整頁、歷史紀錄
js/audio.js            麥克風音量計算（Web Audio API）
js/detector.js         「太吵判定」規則
js/render.js           題目顯示（直式分數）
js/storage.js          本機儲存
js/questions/core.js   題庫核心（隨機出題、避免重複）
js/questions/g4a.js    4 上出題規則
js/questions/g4b.js    4 下出題規則
js/watermark.js        著作權浮水印
tests/check.js         題庫與判定規則自我檢查（node tests/check.js）
textbooks/             課本與考卷（有版權，已排除於 Git 之外）
```

## 開發用：測試模式

網址加上 `?test`（例如 `http://localhost:5173/?test`）會改用假麥克風，可在瀏覽器主控台輸入 `NP.testLevel = 80` 模擬吵鬧、`NP.testLevel = 10` 模擬安靜。上課時不要使用這個網址。
